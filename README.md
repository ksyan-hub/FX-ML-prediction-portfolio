# 試作4: バッチ学習・設定クラス化

USDJPY 5分足データを使い、直近12本の値動きから次の1本の高値を予測するモデルです。
XGBoost を12行ごとに追加学習させ、実運用に近い学習で精度を検証しています。

## 特徴

- 過去12本(1時間分)の OHLC・出来高・スプレッドを1行に平坦化し、72特徴量として使用
- 12行たまるごとに XGBoost を追加学習( `xgb_model` で継続)
- 各行で「予測 → 正解の学習」の順に処理し、未来のデータを先読みしない構成
- 予測値・正解値・二乗誤差(SE)・12回ごとの平均二乗誤差(MSE)を CSV に出力

## ファイル構成

| ファイル | 役割 |
|---|---|
| `train_data_config.py` | 学習期間・対象通貨ペア・ファイルパスの設定 |
| `copy_ratedata_range_to_csv.py` | MT5からレートデータを取得しCSVに保存 |
| `04_treebatch_xgb_USDJPY_5m_.py` | 特徴量作成・バッチ学習・予測・評価の本体処理 |

## 実行方法

1. `train_data_config.py` で期間・通貨ペアを設定
2. `copy_ratedata_range_to_csv.py` を実行しレートデータを取得(MT5端末が起動・ログイン済みであること)
3. `04_treebatch_xgb_USDJPY_5m_.py` を実行し学習・予測を行う
4. `predict_csv/` に結果が出力される

## 動作環境

- Windows(MetaTrader5がWindows 専用のため)
- MT5の口座が必要
- 必要パッケージ: pandas, xgboost, scikit-learn, MetaTrader5, pytz
