# 試作3: 誤差評価(SE・MSE)の導入

試作2のに予測精度を数値で確認する仕組み(SE・MSE)を追加した試作です。
過去12本(1時間分)のOHLC・出来高・スプレッドを特徴量に、次の1本の高値(high)を1行ずつ予測・学習します。

## 特徴

- 過去12本のOHLC・出来高・スプレッドを平坦化し、72特徴量として使用
- 1行ごとに「予測 → 学習」を繰り返すオンライン学習(スクラッチからやり直さず継続学習)
- 12行ごとに二乗誤差(SE)の平均(MSE)を算出しCSVに記録
- 学習期間の設定を "setting_traindata.py" にクラス化(試作4の設定クラスの原型)

## ファイル構成

| ファイル | 役割 |
|---|---|
| "setting_traindata.py" | 学習期間・対象通貨ペアの設定 |
| "copy_ratedata_range_to_csv.py" | MT5からレートデータを取得しCSVに保存 |
| "03_se_mse_xgb_USDJPY_5m_.py" | 特徴量作成・オンライン学習・誤差評価の本体処理 |

## 実行方法

1. `setting_traindata.py` で学習期間を設定
2. `copy_ratedata_range_to_csv.py` を実行しレートデータを取得(MT5端末が起動・ログイン済みであること)
3. `03_se_mse_xgb_USDJPY_5m_.py` を実行し、学習・予測・誤差評価を行う
4. `predict_csv/` に結果が出力される

## 動作環境

- Windows(MetaTrader5がWindowsの専用のため)
- MT5 端末とブローカー口座が必要
- 必要パッケージ: pandas, numpy, xgboost, MetaTrader5, pytz

## 結果

2026/8/11〜8/12のUSDJPYで検証したところ、12回ごとのMSEは概ね0.0003〜0.01(価格差にして約1〜10銭)の範囲で推移しました。安定して縮小する傾向ではなく、相場が動いた局面で誤差が大きくなる様子が見られました。
