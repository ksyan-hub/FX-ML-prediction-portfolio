# 試作2: window特徴量化・時系列オンライン学習

試作1で課題だった正解のlabelと同じ時間足の情報を特徴量に含んでしまっている問題を解消するため、
過去100本(約8時間強)の値動きのみを特徴量として、次の1本の高値(high)を予測する形に変更しました。

## 特徴

- 過去100本の open, high, low, close, tick_volume, real_volume を平坦化し、600特徴量として使用
- 正解ラベルと同じ時刻のデータを一切使わない構成にし、試作1のリークを解消
- 1行ずつ予測 → 学習を繰り返すオンライン学習の形を初めて試した試作(試作3のバッチ学習の原型)

## ファイル構成

| ファイル | 役割 |
|---|---|
| "copy_train_data_to_csv.py" | MT5からレートデータを取得しCSVに保存 |
| "02_100feature_timeseries_xgb_USDJPY_5m_.py" | window特徴量の作成・1行ずつのオンライン学習処理 |
| "predictions.csv" | 予測結果のcsvファイル |

## 実行方法

1. "copy_train_data_to_csv.py" を実行しレートデータを取得(MT5端末が起動・ログイン済みであること)
2. "02_100feature_timeseries_xgb_USDJPY_5m_.py" を実行(学習ループが正しく回るかの動作確認用に、100行ほどで停止する設定になっています)

## 動作環境

- Windows(MetaTrader5 パッケージが Windows 専用のため)
- MetaTrader5のアカウントか口座が必要
- 必要パッケージ: pandas, xgboost, MetaTrader5, pytz
